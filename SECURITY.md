# Security policy

WindowRanger is pre-release software under active private development. A supported public release
channel has not yet been selected.

## Reporting a vulnerability

Do not post suspected vulnerabilities, private diagnostics or reproduction data in a public issue.
No public security contact currently exists, and this repository does not invent one. A private
reporting channel and response expectations will be published before the project is opened publicly.

Until then, people with an existing private relationship to the maintainer should use that existing
channel and share the minimum information needed to reproduce the issue. Remove window titles,
documents, URLs, user file paths and other personal data from logs or screenshots.

## Current support boundary

Only the current development branch is examined during active work. There are no public releases,
security-support windows, signed downloads, update feed, vulnerability bounty or guaranteed response
time. Automated tests and code review do not substitute for later manual security/privacy review,
notarization and release-channel validation.
