# WindowRanger 0.1.0 Beta 10

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

Beta 10 makes multi-display configuration easier to understand, uses the same modern menu-bar
composition across supported macOS releases, and improves workspace previews before their first
visit after launch.

## Highlights

- Compact, Medium, and Full menu-bar modes now use the same grouped display/workspace composition
  on every supported macOS release. Operating-system materials still follow the host macOS version.
- Workspace Layout Style and Orientation controls now show visual examples of Freeform, Tiled,
  Accordion, Automatic, Horizontal, and Vertical behavior instead of relying on names alone.
- Displays Settings now leads with **Switch together** and **Switch separately** choices, keeping
  Unified and Independent as secondary terms. Each reusable display name, this Mac's physical
  monitor, and its plain connection status appear together in one row.
- Inactive Tiled workspace previews reconstruct their intended first-visit layout from saved tree
  geometry. When captured previews are enabled and already authorized, one bounded startup pass
  prepares eligible parked Tiled and Accordion windows at their predicted size so thumbnails do not
  show stale application dimensions. This adds no ongoing timer, scan, or capture work.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.
- Screen Recording permission only when optional captured workspace previews are enabled. The macOS
  permission wording also mentions audio; WindowRanger does not capture audio or the pointer.

## Installation

1. Download `WindowRanger-0.1.0-beta.10.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.10.dmg.sha256`.
3. Use **Quit WindowRanger** in the existing copy, then open the DMG.
4. Drag `WindowRanger.app` onto the Applications shortcut and replace the existing copy when Finder
   asks.
5. Launch WindowRanger from `/Applications`. If macOS asks again, grant Accessibility access to
   `dev.appranger.WindowRanger`.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- The public Sparkle feed remains outside this GitHub release checkpoint, so install Beta 10
  manually from GitHub. Automatic update checking remains off by default.
- Captured workspace previews remain off by default and use a bounded in-memory cache. Their startup
  preparation runs only when capture is enabled and Screen Recording was already authorized.
- Supported physical-Mac, multi-display, clean-user, clean-machine, Accessibility migration,
  privacy, upgrade, and uninstall matrices remain incomplete.
- WindowRanger does not replace or integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.

## Feedback and security

Use the repository issue forms for privacy-safe bugs, feature requests, and questions. Do not post
suspected vulnerabilities, private diagnostics, window titles, document names, URLs, or user file
paths in a public issue; follow `SECURITY.md` instead.
