# WindowRanger 0.1.0 Beta 7

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

Beta 7 brings together the new App Shelf, simpler Settings, consistent keyboard controls, guided
setup, Game Mode profiles, Pause Mode, and the first Sparkle-capable release baseline.

## Highlights

- Quick App Shelf keeps an ordered set of useful apps available across workspaces, with Accordion
  and Carousel presentations, configurable visible-window counts, direct selection, and wrapping
  keyboard navigation.
- Command Palette now combines searchable commands with compact visual Layout and Placement quick
  actions. Keyboard focus moves naturally between the command list and quick actions, while typing
  hides the visual controls and concentrates on search.
- Settings is split into clearer destinations and lets you edit any profile without activating it.
  Profile-owned values remain editable in their natural sections rather than being hidden in one
  oversized Profile page.
- The configurable Navigate and Arrange shortcut families now cover the primary workspace,
  application, layout, placement, and window actions. A passive glass shortcut guide appears while
  either modifier family is held.
- The seven-step branded setup introduces sync, shortcuts, focus borders, menu bar styles, Quick App
  Shelf, and workspace navigation. It can be reopened later from Settings.
- Game Mode profiles can activate for foreground full-screen games, while Pause Mode temporarily
  stops window management and every shortcut except Command Palette so normal control can always be
  restored.
- Stable and Beta builds now contain Sparkle update support with signed archives, explicit local
  Stable/Beta choice, manual checks, and optional automatic checking. This Beta is the installed
  baseline for the first real updater test; the feed intentionally remains inactive until the next
  signed release is ready.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.

## Installation

1. Download `WindowRanger-0.1.0-beta.7.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.7.dmg.sha256`.
3. Use **Quit WindowRanger** in the existing copy, then open the DMG.
4. Drag `WindowRanger.app` onto the Applications shortcut and replace the existing copy when Finder
   asks.
5. Launch WindowRanger from `/Applications`. If macOS asks again, grant Accessibility access to
   `dev.appranger.WindowRanger`.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- The Sparkle feed is intentionally absent for this baseline release. Install Beta 7 from GitHub;
  the next Beta will be used to validate the signed in-app upgrade path.
- Automatic update checking remains off by default while packaged upgrade, cancellation, failure,
  and Beta-to-Stable behavior are validated.
- Game Mode detection depends on the public macOS full-screen/game-session signals available to the
  app and remains best effort for games that do not expose a normal foreground session.
- The complete manual regression, accessibility, privacy, clean-user, and clean-machine matrices
  remain in progress.
- WindowRanger does not replace or integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.

## Feedback and security

Use the repository issue forms for privacy-safe bugs, feature requests, and questions. Do not post
suspected vulnerabilities, private diagnostics, window titles, document names, URLs, or user file
paths in a public issue; follow `SECURITY.md` instead.
