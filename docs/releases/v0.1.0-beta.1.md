# WindowRanger 0.1.0 Beta 1

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

WindowRanger is a native macOS menu-bar workspace manager built around virtual workspaces rather
than native Spaces or a general-purpose command language. This is the first packaged Beta.

## Highlights

- Native Compact, Medium, and Full menu-bar presentations with display-aware virtual workspace
  switching.
- Freeform, Tiled, and Accordion layouts, contextual window commands, directional focus and
  reorder, smart resize, and per-window floating overrides.
- Reusable profiles, application routing rules, multiple-display modes, local recovery state, and
  optional iCloud key-value settings sync.
- Signed and notarized universal app for Apple silicon and Intel Macs, delivered in a
  construction-themed Beta DMG with an Applications shortcut.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.

## Installation

1. Download `WindowRanger-0.1.0-beta.1.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.1.dmg.sha256`.
3. Open the DMG and drag `WindowRanger.app` onto the Applications shortcut.
4. Launch WindowRanger from `/Applications` and grant Accessibility permission when macOS asks.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- This Beta has passed automated tests, static analysis, Developer ID signing, Apple notarization,
  Gatekeeper checks, and a maintainer installation smoke test, but the complete manual regression
  matrix is still in progress.
- Sparkle automatic updates are not included yet; install newer builds manually.
- WindowRanger does not integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.

## Feedback and security

Use the repository issue forms for privacy-safe bugs, feature requests, and questions. Do not post
