# WindowRanger 1.0.8

WindowRanger 1.0.8 fixes a size-rounding case that could stop ordinary windows from tiling.

## Fixed

- Windows that round a requested size by one point remain eligible for tiling. This addresses
  a case seen with Codex where the window could be mistaken for a fixed-size surface.
- Copy Focused Window Diagnostic Report now preserves the report through menu closure, so the
  copy action can replace the clipboard correctly.
- Diagnostic reports include move/resize capability and management-state information to help
  investigate tiling problems.

## Requirements and installation

Requires macOS 14 or later and Accessibility permission. Screen Recording permission is needed
only for optional captured workspace previews.

Download `WindowRanger-1.0.8.dmg`, open it, and drag WindowRanger onto the Applications shortcut.
A notarized ZIP, checksums and provenance manifest are also included. Existing users can use
**Check for Updates…** once the feed is published, or run:

```sh
brew upgrade --cask appranger/tap/windowranger
```

## Known limitations

WindowRanger manages virtual workspaces within the current macOS desktop, rather than replacing
native macOS Spaces. Fixed-size operation windows retain their existing protections.

Use the repository issue forms for privacy-safe feedback. Follow `SECURITY.md` for suspected
vulnerabilities; do not include private diagnostics or window contents in public issues.
