# WindowRanger 1.0.11

WindowRanger 1.0.11 improves workspace placement recovery when applications briefly stop reporting
their windows, particularly when no App Rule assigns the application to a workspace.

## Fixed

- Windows that return and disappear again during wake recovery retain their original workspace
  protection throughout the wake grace period.
- A recently disappeared ordinary window can recover its workspace, saved geometry and layout
  preferences when the same window returns within two minutes. Closed windows still leave the
  live layout promptly so remaining windows can fill the space.

## Diagnostics

- Window discovery and removal records identify whether placement came from recent recovery,
  startup state or the current workspace, without recording window titles or document content.

## Requirements and installation

Requires macOS 14 or later and Accessibility permission. Screen Recording is needed only for
optional captured workspace previews.

Download `WindowRanger-1.0.11.dmg` and drag WindowRanger onto the Applications shortcut. A notarized
ZIP, checksums and provenance manifest are also included. Existing users can use **Check for
Updates…** after the feed is published, or run `brew upgrade --cask appranger/tap/windowranger`.

## Known limitations

Recent placement recovery requires the same process and window identity. It does not reconstruct
windows recreated after an application restart or restore an already-pruned split tree's exact
shape. Application minimum sizes and fixed-size dialog protections remain unchanged.
