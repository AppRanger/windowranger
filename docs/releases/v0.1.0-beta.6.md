# WindowRanger 0.1.0 Beta 6

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

Beta 6 makes WindowRanger's fastest interactions feel like one coherent system: summon a Quick App,
find any action through the Command Palette, position a window without leaving it, and reliably
bring Settings back to the current workspace.

## Highlights

- The new keyboard-first Command Palette searches the actions that are valid for the current
  window, workspace, layout, profile, and applications. An icon-only Placement Halo expands around
  the search control for mouse or arrow-key positioning without closing the palette; the optional
  Globe/Fn hold opens the matching position-only Placement Wheel directly.
- Quick App now hides and unhides its application without the Dock minimize animation, keeps every
  animated path inside the selected display, applies no-animation frames directly, accounts for the
  optional focus border, and launches the configured application when no usable window is open.
- Opening Settings from the menu bar or another command now resurfaces the existing window on the
  current native macOS Space and interaction display while leaving global workspace and Quick App
  shortcuts immediately responsive.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.

## Installation

1. Download `WindowRanger-0.1.0-beta.6.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.6.dmg.sha256`.
3. Use **Quit WindowRanger** in the existing copy, then open the DMG.
4. Drag `WindowRanger.app` onto the Applications shortcut and replace the existing copy when Finder
   asks.
5. Launch WindowRanger from `/Applications`. If macOS asks again, grant Accessibility access to
   `dev.appranger.WindowRanger`.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- The complete manual regression, accessibility, privacy, clean-user, and clean-machine matrices
  remain in progress despite signed daily validation of the changed interactions.
- Quick App deliberately refuses ambiguous multi-window targets. Because its animation-free hidden
  state uses macOS application hiding, other windows belonging to the same application hide and
  unhide with it. Broader two-profile validation remains open.
- The Placement Halo and Wheel expose only positions that are truthful for the active layout. Other
  layout, resize, workspace, profile, recovery, focus, and application actions remain in search.
- Trackpad workspace swiping is off by default and depends on macOS exposing the generic gesture
  stream. System gestures may take precedence.
- Sparkle automatic updates are not included yet; install newer builds manually.
- WindowRanger does not integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.
