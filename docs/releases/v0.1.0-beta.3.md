# WindowRanger 0.1.0 Beta 3

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

Beta 3 improves the Command Wheel, adds profile-aware Quick Apps, strengthens window diagnostics,
and moves WindowRanger's public application identity under AppRanger. Existing settings and the
established iCloud key-value store are preserved, but macOS may require one-time permission and
login-item confirmation because the bundle identifier has changed.

## Highlights

- The Command Wheel has clearer native iconography and geometry, safer destructive actions,
  pointer-window targeting, durable group navigation, and more reliable Globe/Fn hold and click
  behavior.
- Freeform workspaces can place the focused window into display halves or quarters directly from
  the Command Wheel, with preview and Undo/Redo support.
- Each profile can configure one optional Quick App with a global shortcut, interaction-display
  sizing, focus-loss hiding, and top, bottom, left, or right presentation.
- Compact and Medium menu-bar styles on macOS 27 use native per-display status-item groups, while
  older supported macOS versions retain the established compatibility layout.
- Foreground games suspend optional Globe/Fn and workspace-swipe monitoring so ordinary keyboard
  and mouse input stays off WindowRanger's filtering path.
- Window admission diagnostics now expose privacy-safe structured evidence and compatibility
  profiles without broadening which windows WindowRanger controls.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.

## Installation and identity migration

1. Download `WindowRanger-0.1.0-beta.3.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.3.dmg.sha256`.
3. Use **Quit WindowRanger** in the existing copy, then open the DMG.
4. Drag `WindowRanger.app` onto the Applications shortcut and replace the existing copy when Finder
   asks.
5. Launch WindowRanger from `/Applications` and grant Accessibility access to the new
   `dev.appranger.WindowRanger` identity when macOS requests it.
6. Confirm your profiles and settings migrated, then re-enable **Launch at Login** if macOS did not
   retain it across the identity change.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- The complete manual regression, accessibility, privacy, clean-user, and clean-machine matrices
  remain in progress.
- Quick App remains in live validation. It deliberately refuses ambiguous multi-window targets and
  does not launch an application that is not already running.
- The Command Wheel workspace-action icon family is functional but still has a deferred systematic
  SF Symbols review.
- Window admission compatibility profiles currently improve evidence and regression coverage; they
  do not attempt speculative control of apps that expose ambiguous or missing focus information.
- Trackpad workspace swiping is off by default and depends on macOS exposing the generic gesture
  stream. System gestures may take precedence.
- Sparkle automatic updates are not included yet; install newer builds manually.
- WindowRanger does not integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.

## Feedback and security

Use the repository issue forms for privacy-safe bugs, feature requests, and questions. Do not post
suspected vulnerabilities, private diagnostics, window titles, document names, URLs, or user file
paths in a public issue; follow `SECURITY.md` instead.
