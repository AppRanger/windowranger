# WindowRanger 1.0.7

WindowRanger 1.0.7 improves recovery when an application window becomes resizable after previously
being treated as fixed-size.

## Fixed

- A formerly fixed-size window can rejoin Tiled or Accordion after its size changes and macOS
  confirms that it can move and resize again.
- Failed capability checks preserve the window's safe floating state. Fixed-size operation windows
  and ignored panels retain their existing protection.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.
- Screen Recording permission only when optional captured workspace previews are enabled.

## Installation

Download `WindowRanger-1.0.7.dmg` from this release's **Assets**, open it, and drag WindowRanger onto
the Applications shortcut. A notarized ZIP, checksums, and a provenance manifest are also included.

Existing Stable users can install the update through **Check for Updates…** once the feed is
published. Homebrew users can run:

```sh
brew upgrade --cask appranger/tap/windowranger
```

## Known limitations

- WindowRanger manages virtual workspaces inside the current macOS desktop; it does not replace
  native macOS Spaces.
- Recovery requires an observed size change; it does not force repeated resize attempts on an
  unchanged fixed-size window.

## Feedback and security

Use the repository issue forms for privacy-safe feedback. Follow `SECURITY.md` for suspected
vulnerabilities; do not include private diagnostics or window contents in public issues.
