# WindowRanger 0.1.0 Beta 2

> This is pre-release software. Back up important work and use **Quit WindowRanger** before
> replacing an existing build.

Beta 2 is a broad usability and reliability pass over the first public Beta. It keeps the same
profiles and public app identity, so it installs as an in-place update for Beta 1.

## Highlights

- Settings is now freely resizable, uses a cleaner native macOS layout, and switches to familiar
  list/detail navigation at compact widths without losing the selected item.
- The focused window can have a configurable, click-through border, with Tiled-only,
  multiple-window, colour, operating-system radius, and per-app radius controls.
- App Rules can prioritise currently open applications and inherit an unambiguous current workspace;
  workspace and rule controls have also received a consistency pass.
- Display and lifecycle recovery is more defensive after Dock preference changes, full-screen games,
  display changes, and sleep/wake.
- Command feedback uses a native static Liquid Glass pill on supported macOS releases, with the
  system HUD material retained on older supported releases.
- An optional local three- or four-finger horizontal trackpad gesture cycles workspaces with
  wraparound through the existing display-aware workspace command path.

## Requirements

- macOS 14 or later.
- Accessibility permission for window discovery and management.

## Installation

1. Download `WindowRanger-0.1.0-beta.2.dmg` from this release's **Assets** section.
2. Optionally verify it against `WindowRanger-0.1.0-beta.2.dmg.sha256`.
3. Use **Quit WindowRanger** in the existing copy, then open the DMG.
4. Drag `WindowRanger.app` onto the Applications shortcut and replace Beta 1 when Finder asks.
5. Launch WindowRanger from `/Applications` and confirm its Accessibility permission remains active.

The notarized ZIP and its checksum are included as a fallback for environments that cannot mount a
DMG. GitHub's automatically generated source archives do not contain the installable application.

## Known limitations

- The complete manual regression, accessibility, privacy, clean-user, and clean-machine matrices
  remain in progress.
- Trackpad workspace swiping is off by default and depends on macOS exposing the generic gesture
  stream. System gestures may take precedence, and compatibility across supported macOS releases
  still needs physical-hardware validation.
- The focused-window border deliberately excludes full-screen games and apps identified as games.
  Some applications that do not expose a reliable focused Accessibility window may remain
  unbordered.
- Sleep/wake and topology recovery are intentionally defensive, but intermittent physical lifecycle
  cases still require live multi-display testing.
- Sparkle automatic updates are not included yet; install newer builds manually.
- WindowRanger does not integrate with native macOS Spaces.
- Quit other window managers that use overlapping global shortcuts before testing WindowRanger.

## Feedback and security

Use the repository issue forms for privacy-safe bugs, feature requests, and questions. Do not post
