# WindowRanger support

WindowRanger is pre-release software. There are no supported releases, signed public downloads, or
guaranteed response times yet.

## Getting help

Before opening an issue:

1. Read the [README](README.md), especially the current behaviour and limits.
2. Check [Permissions and Privacy](docs/permissions-and-privacy.md) for Accessibility setup.
3. Search existing issues for the same symptom.
4. Confirm you are running the intended signed build and have gracefully quit any older copy.

Use the repository's **Question or support request** issue form for build and usage questions. Use
the **Bug report** form for reproducible defects and the **Feature request** form for product ideas.

Support is best effort. Maintainers may close questions that cannot be reproduced, fall outside the
documented project scope, or require private user data to investigate.

## Privacy and security

Never post unredacted diagnostics, window titles, document names, URLs, typed content, full file
paths, credentials, or personal screenshots in an issue. Share the smallest privacy-safe excerpt
needed to reproduce a problem.

Suspected vulnerabilities must follow the [Security Policy](SECURITY.md), not the public issue
tracker. Conduct concerns must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
